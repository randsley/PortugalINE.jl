PortugalINE.jl

A client for Statistics Portugal (INE), built for spatial work: the geography codes, the indicator API, CAOP boundaries, contiguity weights, and the join between them.

The README records, with measurements, the traps this package exists to avoid: codes that are not seven digits, NUTS codes that change between vintages, two parish maps, pseudo-units in the data, and an API that answers failure with HTTP 200.

PortugalINE — Module
PortugalINE

A client for Statistics Portugal (INE), built for spatial work: the geography codes, the indicator API, and weights matrices from INE's own geometry.

Data from INE is open for reuse, commercially and otherwise, under EU Directive 2019/1024. INE retains copyright, and reuse carries one condition: cite the source. This package records provenance with every extract so that citation can be written without guessing when the data was pulled.

Licences

INE's data is open for reuse under EU Directive 2019/1024; the one condition is that the source be cited (ine_citation). CAOP is published by the Direção-Geral do Território under CC-BY-4.0 (CAOP_ATTRIBUTION). Every file this package writes carries both.
