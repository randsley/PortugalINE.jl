Web maps

PortugalINE.Web — Module
Web

Layer 6: boundaries and data as files a browser map draws. Web maps (MapLibre, deck.gl, D3) want longitude and latitude, small files, and borders that stay shared when they are simplified, so neighbouring units do not open slivers or overlap. This layer reprojects, simplifies each shared border once, and writes TopoJSON beside the values and the weights' links.

The geometry it writes is for display only. Simplification moves vertices, so weights computed from it would differ from the exact ones; the GAL files are the weights.

PortugalINE.Web.ptm06_to_wgs84 — Method
ptm06_to_wgs84(x, y) -> (lon, lat)

Convert a point in EPSG:3763 (PT-TM06/ETRS89, metres: the coordinates of CAOP's mainland GeoPackages) to longitude and latitude in degrees. Pure Julia, checked against PROJ to 1e-9 degrees (a tenth of a millimetre).

PortugalINE.Web.write_webmap — Function
write_webmap(dir, p::PanelDataset; crs, name = "portugal_parishes_panel", tolerance = 20.0)
write_webmap(dir, ds::MunicipalDataset; crs, name = "portugal_municipalities", tolerance = 20.0)

Write what a browser map needs, for the units of a panel or a dataset:

  • <name>.topo.json: TopoJSON in longitude and latitude, one object units with each unit's code as id and its name as the dataset keeps it (INE's). Each shared border is one arc, simplified once (Douglas-Peucker, tolerance metres), so neighbours stay flush. Coordinates are quantised to a 10⁶ grid, about half a metre.
  • <name>.values.json: the codes, the periods and every column, as values[period][unit] (null where INE suppressed the cell), with the indicator and filter of each column.
  • <name>.links.json: the weights' links as pairs of 0-based unit indices, i < j, and each unit's centroid in longitude and latitude, to draw W as a network.
  • <name>_WEBMAP.md: provenance, both credits, and how the geometry was changed.

crs is the boundaries' coordinate system, "EPSG:3763" for CAOP's mainland GeoPackages and "EPSG:4326" for DGT's OGC API; it is required because the boundaries do not record it. The geometry is for display: weights come from the GAL files, which use the exact vertices.
